## Overview:
This is a Javascript application that generates Breaking Bad-style aliases by combining your name with random last names from the Breaking Bad Universe.

## Features:
- Generating unique aliases
- Custom Character Count (you get to choose how many letters to use)
- No repeat last name logic
- 5 alias suggested, you get more options!!
- Handles short names with grace
- Extracts first name from full names

## Tech Stacks Used:
Node.js
Jest for testing

## Quick Start:
npm install
npm start
